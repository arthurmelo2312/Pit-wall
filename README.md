# Pit Wall — GP de São Paulo

Página web estática de demonstração sobre o Grande Prêmio de São Paulo, com destaque para Interlagos, uma grade de pilotos, uma classificação fictícia e opções ilustrativas de ingressos.

## Funcionalidades

- Layout responsivo para celular e desktop.
- Navegação entre as seções de pilotos, classificação e ingressos.
- Imagem de destaque do piloto na página inicial.
- Formulário visual para demonstrar interesse em ingressos.

> Os pilotos, resultados e preços são apenas exemplos. O formulário não envia nem armazena dados.

## Tecnologias

- HTML5
- CSS3
- Google Fonts: Inter e Barlow Condensed

## Como executar

1. Abra a pasta do projeto no VS Code.
2. Abra `index.html` em um navegador. Se tiver a extensão Live Server instalada, você também pode clicar com o botão direito no arquivo e selecionar **Open with Live Server**.

Não é necessário instalar dependências ou executar um processo de build.

## Estrutura do projeto

```text
pit-wall/
├── index.html
├── styles.css
├── img/
│   └── piloto.jpg
└── Pit wall/
    └── README.md
```

O HTML carrega `styles.css` e a imagem da página inicial está em `img/piloto.jpg`. Mantenha essa estrutura de arquivos para que os caminhos relativos continuem funcionando.
